# Global Genomic Epidemiology of the Enterobacter cloacae Complex (2000–2026)

## Overview

This repository contains computational analysis workflows for a global genomic epidemiology study of the *Enterobacter cloacae* complex (ECC), encompassing 9,157 publicly available bacterial genome assemblies collected between 2000 and 2026.

The study investigates antimicrobial resistance, multilocus sequence typing, species diversity, geographical distribution, One Health reservoirs, socioeconomic stratification, and plasmid replicon–AMR gene co-occurrence.

## Computational analyses

- Genome metadata curation and quality assessment
- Multilocus sequence typing (MLST)
- AMR gene identification using AMRFinderPlus
- Plasmid replicon identification using PlasmidFinder
- Temporal, geographical and One Health comparisons
- Statistical analysis and visualization of Figures 1–7

## Reproducibility

Analysis scripts, software requirements, and supporting source data will be organized in this repository as they are finalized. The presence of a script does not independently establish that its results have been validated.

## AI-assisted code development

Python scripts were generated with assistance from OpenAI's ChatGPT using researcher-defined analytical requirements. The researcher is responsible for reviewing and validating the computational workflows and scientific results.
